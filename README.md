# 분수의 나눗셈 실험실

초등학교 **6학년 2학기 수학 1단원 「분수의 나눗셈」**을 조작 활동으로 익히는 학습 웹 앱입니다.
2022 개정 교육과정 성취기준 **[6수01-11]** 분수의 나눗셈의 계산 원리를 탐구하고 그 계산을 할 수 있다.

## 학생 접속 주소

<https://junho1-commits.github.io/fraction-division-lab/>

주소만 알면 로그인 없이 바로 쓸 수 있습니다. 크롬 주소창 오른쪽의 설치 아이콘이나 앱 안의
**「앱 설치」** 버튼을 누르면 바탕화면 아이콘이 생기고, 그다음부터는 **인터넷이 끊겨도** 동작합니다.

## 구성

여섯 차시가 각각 네 단계로 나뉘어 있고, 앞 단계를 해결해야 다음 단계가 열립니다.

| | 단계 | 하는 일 |
|---|---|---|
| 1 | 구체물로 조작하기 | 끌어 옮기기·자르기·담기 — 손으로 해 본다 |
| 2 | 그림으로 나타내기 | 막대·수직선·원판으로 확인한다 |
| 3 | 식으로 쓰기 | 조작한 것을 식으로 옮긴다 |
| 4 | 규칙 찾고 연습하기 | 규칙을 만들고 네 문제를 푼다 |

| 차시 | 내용 | 대표 문제 |
|---|---|---|
| 1 | 분모가 같은 (분수)÷(분수) ① 나누어떨어지는 경우 | 7/10 ÷ 1/10 = 7 |
| 2 | 분모가 같은 (분수)÷(분수) ② 나누어떨어지지 않는 경우 | 5/7 ÷ 2/7 = 2½ |
| 3 | 분모가 다른 (분수)÷(분수) | 3/4 ÷ 4/7 = 1 5/16 |
| 4 | (자연수)÷(분수) | 6 ÷ 2/3 = 9 |
| 5 | (분수)÷(분수)를 분수의 곱셈으로 | 4/5 ÷ 2/3 = 4/5 × 3/2 |
| 6 | (대분수)÷(분수) | 4½ ÷ 3/4 = 6 |

## 오개념 차단 장치

- **분모끼리 나누기** — 분모 카드를 놓으면 거부하고 이유를 설명
- **몫을 "2 나머지 1/7"로 쓰기** — 같은 조각을 두 기준에 넣어 보게 함
- **나누면 항상 작아진다** — 예상한 뒤 슬라이더로 6÷1/3=18까지 직접 확인
- **앞의 분수를 뒤집기** — 앞 분수 카드를 누르면 흔들리며 거부
- **대분수를 그대로 나누기** — 전용 버튼이 이유를 설명하며 막음
- 빈칸은 **틀린 값에 따라 다른 힌트**를 보여 줍니다

## 학습 기록

학생이 어디까지 했는지는 **그 기기의 브라우저에만** 저장됩니다(localStorage). 교사나 서버로
전송되지 않고, 개인정보를 수집하지 않습니다. 기기를 바꾸면 기록은 초기화됩니다.
오른쪽 위 **「기록 지우기」**로 언제든 초기화할 수 있습니다.

브라우저 저장이 막힌 환경(파일로 열었을 때 등)에서는 앱이 이를 스스로 알아채고 홈 화면에
안내를 띄우며, 상단에 **「진행 저장」·「진행 불러오기」** 버튼이 나타납니다. 수업 끝에 기록
파일(`분수나눗셈-진행기록-YYYYMMDD.json`)을 내려받아 두면 다음 시간에 그 파일을 골라 이어
할 수 있습니다. 내려받지 않아도 그 시간의 학습은 정상 진행됩니다.

## 파일 구성

```
app.source.html         원본 소스 — 내용을 고칠 때는 이 파일을 고친다
build.py                app.source.html → index.html 생성 (python build.py)
index.html              배포용 결과물 (원본 + 설치·오프라인·검색차단)
manifest.webmanifest    설치 정보 (앱 이름·아이콘·색)
sw.js                   오프라인 지원 서비스 워커
robots.txt              검색엔진 색인 차단
icons/                  앱 아이콘 (192·512·마스커블·애플)
```

빌드 도구가 필요 없습니다. `index.html`만 있으면 USB나 공유 폴더에서 파일로 열어도 동작합니다
(그 경우 설치·오프라인 기능만 빠집니다).

## 수정하는 방법

`index.html`을 열어 아래 위치를 고칩니다.

- 색·글꼴·크기 → 파일 앞부분 `<style>` 안의 `:root` 토큰
- 차시·단계 내용 → `LESSONS.push({ ... })` 블록 (차시마다 하나, `steps` 배열에 네 단계)
- 문제와 정답 → 각 단계의 `answers`(정답), `hints`(틀린 값별 안내), `tip`(두 번 틀리면 나오는 힌트)

고친 뒤 커밋하고 푸시하면 1~2분 안에 위 주소에 반영됩니다.

```bash
git add -A && git commit -m "내용 수정" && git push
```

`sw.js`의 `CACHE` 값(`fdlab-v1`)을 올리면 이미 설치한 학생 기기에서도 새 버전을 확실히 받아 갑니다.
